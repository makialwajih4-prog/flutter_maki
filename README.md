# تطبيق فلاتر العملي

هذا المشروع هو حل تكليف المحاضرات الرابعة والخامسة والسادسة والسابعة في Flutter، ويطبّق الواجهات والسلوكيات الموضحة في نهاية الملزمة.

## الواجهات المنفذة

- بطاقة الطالب مع `MaterialApp` وواجهة هبوط مستقلة.
- واجهة `Scaffold` مع `AppBar` و`Drawer` و`FloatingActionButton` و`NavigationBar`.
- لوحة تحكم تحتوي أربع بطاقات: الإحصائيات، المستخدمين، الرسائل، والإعدادات.
- قائمة منتجات باستخدام `ListView`.
- قائمة مخزون بعناصر وأسهم انتقال.
- واجهة `Stack` تحتوي بطاقة زرقاء وزر تشغيل في المنتصف.
- عداد يعمل بواسطة `StatefulWidget` ويدعم الزيادة والتنقيص.
- نافذة `AlertDialog` ورسالة `SnackBar`.
- حقل `TextField` للتحقق من بريد Gmail مع رسالة نجاح أو فشل.

## التشغيل

بعد تثبيت Flutter، من داخل مجلد المشروع نفّذ:

```bash
flutter pub get
flutter run
```

نقطة البداية هي `lib/main.dart`، وكل واجهة موجودة داخل class مستقل باسم واضح.
